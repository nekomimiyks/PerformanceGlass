PerformanceGlass / Windows 10・11（64bit）

Extract all files and run PerformanceGlass.exe. Basic monitoring works without installation or admin rights.
The UI follows your Windows display language; English is used if unsupported.
Double-click the graph / F11: graph-only view. Right-click / F10: settings and Exit.
Switching the frame preserves the graph size and position.
Right-click > Language: follow Windows or choose a language. Changes are saved.
Right-click > Taskbar graph: choose a metric for the mini graph (CPU usage by default).
Right-click > Keep in system tray: enable tray residency (off by default).
Right-click > CPU temperature monitoring: if PawnIO is missing or outdated, confirm to open the bundled official installer.
The GitHub EXE is unsigned. Microsoft Store: https://apps.microsoft.com/detail/9PJ34ZZHSD01

ZIPをすべて展開し、PerformanceGlass.exeを起動してください。
基本機能はインストール・管理者権限なしで使えます。

グラフをダブルクリック / F11：グラフ専用表示の切り替え
枠の切り替え前後でグラフのサイズと位置を保持します。
辺や角をドラッグ：サイズ変更
右クリック / F10：設定・自動起動・終了
右クリック → 言語：Windowsに合わせる自動設定／12言語を選択。即時反映・保存。
右クリック → タスクバーのグラフ：ミニグラフの表示項目を選択（既定はCPU使用率）。
右クリック → CPU温度の計測：対応するPawnIOが未導入なら確認が表示され、許可すると同梱の公式インストーラーが開きます。
右クリック → タスクトレイに常駐：有効にすると×や最小化で通知領域に格納（既定はオフ）。
常駐オフの場合は、×で終了し、最小化でタスクバーに残ります。

PerformanceGlass / Windows 10・11（64bit）

Extract all files and run PerformanceGlass.exe. No installation or admin rights needed.
The UI follows your Windows display language; English is used if unsupported.
Double-click the graph / F11: graph-only view. Right-click / F10: settings and Exit.
Switching the frame preserves the graph size and position.
Right-click > Language: follow Windows or choose a language. Changes are saved.
The GitHub EXE is unsigned. Microsoft Store certification is pending.

ZIPをすべて展開し、PerformanceGlass.exeを起動してください。
インストール・管理者権限・追加ランタイムは不要です。

グラフをダブルクリック / F11：グラフ専用表示の切り替え
枠の切り替え前後でグラフのサイズと位置を保持します。
辺や角をドラッグ：サイズ変更
右クリック / F10：設定・自動起動・終了
右クリック → 言語：Windowsに合わせる自動設定／12言語を選択。即時反映・保存。
×：通知領域へ格納（終了は右クリックメニュー）

# v0.1.13の性能測定

AMD Ryzen 7 5800X搭載のWindows 11 x64環境で、v0.1.12とv0.1.13の性能改善を比較しました。両方を同じRust／MinGWのリリース設定でビルドし、固定のサンプルデータで測定しました。

## 履歴の集約

43,201件のサンプルを用意し、各表示期間の履歴をグラフの横幅に合わせて集約する時間を測りました。30回のウォームアップ後に300回ずつ測定し、3セットの中央値を取りました。

| 表示期間（幅960px） | v0.1.12 | 改善後 | 短縮率 |
| --- | ---: | ---: | ---: |
| 1分 | 4.03 µs | 3.78 µs | 約6% |
| 10分 | 15.15 µs | 12.85 µs | 約15% |
| 60分 | 73.01 µs | 58.83 µs | 約19% |
| 6時間 | 423.93 µs | 339.67 µs | 約20% |
| 12時間 | 850.88 µs | 698.90 µs | 約18% |

値は集約1回あたりの時間です。幅280pxと1920pxでも、全5期間で集約時間が短縮しました。

## グラフの描画

30フレームのウォームアップ後、300フレームを連続描画し、1フレームあたりの時間を比較しました。グラフ専用表示（280×60px、12時間）では中央値が1.68msから1.36msに短縮しました（約19%）。大きな通常表示（1440×720px、12時間）では描画全体の短縮は確認できませんでした。

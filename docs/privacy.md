# プライバシーポリシー

最終更新日 2026年11月24日

PerformanceGlassはWindowsのCPU・メモリ・ディスク・ネットワーク・GPUの使用状況や、利用可能な温度センサーの値を表示するアプリです。

アプリは計測値、個人情報、利用状況を外部へ送信しません。広告、解析サービス、アカウント登録、アプリ内のオンライン機能はありません。ネットワークの送受信速度はWindowsのローカル統計から取得します。CPU温度は、同じPC内の補助プログラムまたはWMIプロバイダーから取得します。

グラフ履歴はメモリ上だけに保持し、終了時に消えます。表示期間、表示項目、ウィンドウの位置・サイズなどの設定をWindowsのローカルアプリデータ領域に保存します。GitHub版の保存先は `%LOCALAPPDATA%\PerformanceGlass\settings.txt` です。Store版ではWindowsによるパッケージ単位の保存先の管理が適用されます。

設定のバックアップは利用者が指定した場所にファイルとして保存します。ファイルには表示言語やウィンドウ位置などの設定が含まれます。アプリによる外部送信はありません。

自動起動は利用者が有効にした場合だけ設定します。GitHub版でCPU温度を有効にし、対応するPawnIOが未導入の場合は、アプリ内で許可を得てから同梱の公式インストーラーを起動します。計測に管理者権限が必要な場合も、アプリ内で許可を得てからWindowsに権限を要求します。計測時の許可または拒否は、利用者が指定した場合だけ保存します。

Microsoft Storeによる配布・更新・診断情報などの取り扱いには、Microsoft側のプライバシーポリシーが別途適用されます。

お問い合わせは[GitHub Issues](https://github.com/nekomimiyks/PerformanceGlass/issues)をご利用ください。公開の場のため、住所・認証情報などの個人情報を書き込まないでください。

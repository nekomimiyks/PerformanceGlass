# プライバシーポリシー

最終更新: 2026年11月17日

PerformanceGlassはWindowsのCPU・メモリ・ディスク・ネットワーク・GPUの使用状況や、利用可能な温度センサーの値を表示するアプリです。

アプリは計測値、個人情報、利用状況を外部へ送信しません。広告、解析サービス、アカウント登録、アプリ内のオンライン機能はありません。ネットワークの送受信速度はWindowsのローカル統計から取得します。CPU温度の連携先も、同じPC上のWMIプロバイダーに限られます。

グラフ履歴はメモリ上だけに保持し、終了時に消えます。表示期間、表示項目、ウィンドウの位置・サイズなどの設定をWindowsのローカルアプリデータ領域に保存します。ZIP版の保存先は `%LOCALAPPDATA%\PerformanceGlass\settings.txt` です。Store版ではWindowsによるパッケージ単位の保存先の管理が適用されます。

自動起動は利用者が有効にした場合だけ設定します。セキュリティーソフトの設定変更、管理者権限の要求、ドライバーの導入は行いません。

Microsoft Storeによる配布・更新・診断情報などの取り扱いには、Microsoft側のプライバシーポリシーが別途適用されます。

お問い合わせは[GitHub Issues](https://github.com/nekomimiyks/PerformanceGlass/issues)をご利用ください。公開の場のため、住所・認証情報などの個人情報を書き込まないでください。

# Performance Glass アイコン

採用原稿: `performance-glass.svg`。1024 × 1024、外周透過。外部画像・フォント・フィルターを使わないベクター原稿。

深い紺色のガラス窓に、ミント色の太いグラフと青い補助グラフを重ねた。二つの系列を一つの窓で見るアプリの特徴を表現する。斜めの反射と明るい縁が「Glass」、上向く折れ線が「Performance」を示す。文字やOSロゴに頼らず、シルエットと色で識別する。

外形はキャンバスの87.5%。濃紺の面はライト背景、明るい縁とグラフはダーク背景で輪郭を保つ。窓の中は不透明なので、背後の壁紙で線のコントラストが変わらない。

16pxでは主線は約1.25px、縁は約0.5px。補助線と反射が弱く見えても、主線と窓の形が残る設計。16 / 24 / 32pxはそれぞれSVGから直接書き出し、PNGの連続縮小を避ける。ICOには各実寸の画像を収録し、透明ピクセルの黒い縁取りが出ないアルファ対応の変換を使う。単色トレイアイコンが必要になった場合は、別途専用図案を作る。

Microsoft Storeの画像では、この原稿を各指定キャンバスの中央へ配置する。背景色が必要な掲載画像は書き出し側で付与し、原稿の外周透過を保つ。
